# Library Loans

Borrow and return books at the university library.

Members borrow up to five books for 14 days and return them at the desk. Staff see which loans
are overdue.

## Layout

| Path | What |
|---|---|
| `src/main/java/loans/` | Books, loans and the lending rules (Java) |
